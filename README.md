## Download: [Here](https://modrinth.com/datapack/smp-starter)

With this datapack/mod, administrators can define a spawn point for the server start and, using a simple command, set a world border, disable PvP, and switch all players to Adventure mode. When another command is executed, the world border resets to its original size with an animation, PvP is re-enabled, and all players are switched to Survival mode. Day time and weather are also switched accordingly.

Anyone with the tag 'admin' will not be switched to any other game mode.

### Usage:
1. Put the file in the mods or datapack folder.
1. Start the World or Server.
1. Find a place where the Worldspawn should be.
1. Run /function smpstart:setup
1. Whitelist all your friends.
1. Run /function smpstart:startsmp 

Once the server start is finished, the mod/datapack can be removed without any problems.
